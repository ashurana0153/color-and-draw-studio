# Calm Colors

A paint-by-number coloring book for adults. Pick a fine-line picture, match the red numbers to the numbered paint pots and color it in by hand with a brush. Paint is free-hand, so it can spill over the lines like on real canvas.

- Categories: Nature, Superheroes (original stained-glass heroes), Arts
- Brushes in four sizes, eraser, undo, zoom and pan, optional "In lines" assist
- Paintings are saved on the device (IndexedDB)
- Vanilla ES modules and canvas, no build step: serve the folder statically

Live: https://ashurana0153.github.io/calm-colors/
